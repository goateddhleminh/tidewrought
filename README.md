# Tidewrought: Idle Pixel Fishing

A complete idle/incremental pixel-art browser fishing game built with **React + TypeScript + Vite + Tailwind CSS**.

🔗 **Play Live:** [https://goateddhleminh.github.io/tidewrought/](https://goateddhleminh.github.io/tidewrought/)

## Features
- **Pixel-Art Dock Scene**: Integer-scaled `192×108` canvas with 5 zones (*Sunny Pond*, *Mangrove Creek*, *Coral Reef*, *Abyssal Trench*, *Starlit Void Lake*), 8 rod tiers, dynamic weather/day-night overlays, and dock helpers.
- **Deep RNG Layer**: 6 rarity tiers with a diminishing-returns Luck curve, 7 stackable independent mutations (*Shiny*, *Giant*, *Tiny*, *Golden*, *Cursed*, *Glitched*, *Prismatic*), Epic/Legendary pity counters, Hot Streaks, Double Catches, and Treasure Chests.
- **65 Fish Species & Codex**: 30 base sprites from the Tidewrought Asset Pack + 35 weather/time-of-day variants, with milestone and per-zone completion rewards.
- **Progression & Prestige**: Tackle upgrades, 4 Dock Helpers, Bait gambling & crafting, 30 Relics, Fate Altar mutation/relic rerolling, 15-skill tree, Tide Reset prestige for Pearls, Deep Dive endless mode, and 45 achievements.

## Local Development

npm install
